# 月の満ち欠け・日食月食シミュレーター

ブラウザ上で太陽・地球・月の位置関係を操作しながら、**月の満ち欠け**と**日食・月食の発生条件**を同時に視覚的に理解できる Web 教材です。高校地学・地学基礎の定番単元を、平面図ではなく実際の天体配置と対応づけて学べます。

天体の位置は簡易暦計算（Meeus『Astronomical Algorithms』の低精度式）で求めているため、**実際の日付の月の形や、実在の日食・月食**（例：2026年3月3日の皆既月食、2026年8月12日の皆既日食）をそのまま再現できます。

## 主な機能

### 可視化ビュー
- **俯瞰ビュー**（北極側から見た図）
  - 地球中心モード：太陽の光・地球の影（本影/半影）・白道の北側/南側・昇交点/降交点・太陽からの角度を表示
  - **8つの月相ガイド**：軌道上の月と「地球から見た形」を対応づけて表示
  - 月を**ドラッグ**して好きな位置へ動かせる（ホイールでズーム）
  - 太陽中心モード：地球の公転と交点線の向きを表示し、交点線が太陽を向く「食の季節」を強調
- **地球から見た月**：南中のころの空の色・地平線とともに、満ち欠けを描画。月食では地球の影の位置を実際の角度で重ね、日食では太陽と月の重なりを表示
- **食の判定図**：太陽（新月のころ）または地球の影（満月のころ）のまわりを実角度で描き、月の通り道と「食が起こるゾーン」を表示。毎月食が起きない理由がひと目でわかる
- **タイムライン**：1年分の月の明るさ・新月/満月・日食/月食・食の季節を表示。クリック/ドラッグ/キーボードで時刻を移動

### 操作パネル
- 再生・一時停止・速さ（1秒＝1時間〜64日）、±1時間/±1日、日付入力、「今日」
- 月の位置（太陽からの角度）スライダー、次の新月/上弦/満月/下弦へジャンプ
- 前後の日食・月食へジャンプ、再生中に食が起きたら自動で一時停止
- 白道の傾き（5.14°）ON/OFF：OFF にすると毎月食が起きる「もしも」の世界を体験
- 表示モード・ガイド・ズーム・回転の切替、キーボード操作（Space / ← → / Shift+← →）

### 学習パネル
- **解説**：いまの月（月相・月齢・輝面比・暦の和名・月の出/南中/月の入）、位置関係、**食の条件チェック**（2条件をメーター表示）、状況に応じた観察のポイント、よくある疑問
- **ミッション**：「上弦の月をつくろう」「本物の皆既月食を見つけよう」など9つの課題を自動判定（進捗はブラウザに保存）
- **クイズ**：月の形→名前／配置→月の形／見える時刻・方角／食のしくみ（誤解しやすいポイント）。解説つき・連続正解記録・シミュレーターで確かめるボタン
- **食カレンダー**：表示中の年の日食・月食一覧からジャンプ
- **用語**：月相・離角・輝面比・黄道と白道・交点・本影と半影・食の季節・サロス周期など

### その他
- 日本語 / English 切替、ライト / ダーク切替、PC・タブレット・スマホ対応
- 現在の状態を共有できるリンクのコピー（`?t=日時&tilt=0&mode=helio&lang=en`）
- 初回訪問時の使い方ガイド

## 技術

- Vanilla JavaScript (ES modules) + HTML + CSS + Canvas 2D（高解像度ディスプレイ対応）
- ビルド不要。そのまま GitHub Pages で配信できます（`.github/workflows/deploy.yml`）

| ファイル | 役割 |
| --- | --- |
| `js/simulation.js` | 太陽・月の位置、月相、食の判定、新月/満月・食の探索 |
| `js/overheadView.js` | 俯瞰ビュー（地球中心 / 太陽中心、ドラッグ操作） |
| `js/moonView.js` | 地球から見た月（満ち欠け・月食・日食の描画） |
| `js/eclipseChart.js` | 食の判定図 |
| `js/timeline.js` | 1年のタイムライン |
| `js/learningTexts.js` | 解説・よくある疑問・用語集 |
| `js/quiz.js` / `js/missions.js` | クイズ / ミッション |
| `js/i18n.js` | 日本語・英語の UI 文言 |

## ローカル実行

任意の静的サーバで起動してください。

```sh
python3 -m http.server 8080
# または
npx serve .
```

ブラウザで `http://localhost:8080/` を開きます。

## テスト

計算部分は Node.js（v18 以降）の標準テストランナーで確認できます。2024〜2028 年のすべての日食・月食（22 件）の日時と種類が再現されることなどを検証します。

```sh
node --test
```

## 注意

教育用途のシミュレータです。天体の位置は近似計算（月の位置で 0.1° 程度の誤差）で、俯瞰ビューの距離・大きさは見やすさを優先して描いています。食の判定は地球全体で見られるかどうかの判定で、特定の地点での見え方や時刻の予報には使用しないでください。
